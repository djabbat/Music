## Ze State Machine (композиционный движок)

| State | v_target | τ_target | χ_target | Смысл |
|-------|----------|----------|----------|-------|
| CALM | 0.00 | 0.12 | 0.20 | Покой, вступление |
| BUILD | +0.18 | 0.16 | 0.45 | Нарастание, ария |
| PEAK | +0.35 | 0.12 | 0.75 | Кульминация, хор |
| RESOLVE | −0.10 | 0.15 | 0.35 | Катарсис, финал |
| DRONE | +0.02 | 0.10 | 0.25 | Бурдон, ритуал |
| DRAMATIC | −0.25 | 0.14 | 0.85 | Драма, конфликт |
| COMPLEX | +0.05 | 0.22 | 0.50 | Полифония, речитатив |
| GROOVE | +0.30 | 0.10 | 0.55 | Танец, победа |

## Valid Transitions

```
CALM    → BUILD, DRONE, COMPLEX
BUILD   → PEAK, DRAMATIC, COMPLEX
PEAK    → RESOLVE, GROOVE, CALM
RESOLVE → CALM, BUILD, DRONE
GROOVE  → PEAK, RESOLVE, BUILD
COMPLEX → RESOLVE, PEAK, CALM
DRONE   → BUILD, DRAMATIC, CALM
DRAMATIC→ RESOLVE, PEAK, COMPLEX
```
