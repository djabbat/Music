# Threshold Stand — Правила для pi
**Проект:** Опера «Threshold Stand» — Ze-опера в 3 актах
**Родительский проект:** Music (Ze-MIM)
**Дата создания:** 2026-07-27
**Композитор:** Ze-MIM System (Jaba Tqemaladze, MD)

## Правила проекта
1. **Вся опера — через Ze State Machine.** 8 состояний: CALM, BUILD, PEAK, RESOLVE, DRONE, DRAMATIC, COMPLEX, GROOVE.
2. **Три акта — три традиции:** Акт I (Грузия), Акт II (Моцарт+Орф), Акт III (Рок+Синтез).
3. **4 вокальных стиля:** aria, chorus, recit, orchestral.
4. **Партитура — в Ze-нотации:** T/S-события + v/τ/χ параметры для каждой секции.
5. **MIDI — основной формат.** Исходный код генерации в `opera_generator.py`.
