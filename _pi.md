# Music — Правила для pi

**Проект:** Ze Music — анализ и синтез музыки через Ze-теорию
**Родительский проект:** Marketing
**Дата создания:** 2026-07-27

## Правила проекта

1. **Ze-теория — математическая основа.** Все музыкальные анализы и генерации — через Ze-векторы (T/S события, v, τ, Z, χ, ζ).
2. **Три композитора:** Бах (фуга, v*, максимальная τ), Моцарт (соната, золотое сечение), Орф (остинато, высокая ζ).
3. **Код — на Python.** `ze_music.py` в корне проекта.
4. **MIDI — основной формат.** Вход: MIDI-файлы. Выход: MIDI-файлы + Ze-анализ.
5. **Маркетинговая цель:** продукт для музыкантов, композиторов, музыковедов, образовательных учреждений.
